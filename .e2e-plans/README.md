# E2E Test Plans

This directory contains End-to-End (E2E) test plans for this project. Plans are written for a Playwright-based testing agent.

## Plans

- [admin](admin.md) — Admin subproject E2E test plan (v8.0.0, 6 workflows)

## Usage

The plans here assume the testing agent has Playwright (browser automation) tools available and no prior knowledge of the project internals. Each workflow includes step-by-step actions, selectors, expected outcomes, and edge cases.
